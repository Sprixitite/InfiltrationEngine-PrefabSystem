# GenericPrefab_Prop_Escort
Animates a prop (assigned the specified prop tag) along a node-based path, with the speed the prop moves along the path controlled by an external variable

This prop exposes a means to determine how many players are near the escort point, the size of the escort point may be set per-prefabinstance, the player count may be used to calculate the rate of progress for the escort

## Dependencies:

- [PropPathAttachment](../PropPathAttachment/)
